# SOLANA AI MEME COIN HUNTER & AUTONOMOUS TRADING SYSTEM

Production-oriented autonomous meme coin scanner, risk analysis engine, and execution system for Solana Mainnet.

## Architecture

- **Frontend**: Next.js 15 (React 19), TypeScript, Tailwind CSS (Mobile-First UI).
- **Backend**: Python 3.11+, FastAPI (Async worker architecture).
- **Database**: PostgreSQL with SQLAlchemy ORM & Alembic migrations.
- **Blockchain Integration**: Solana RPC (Helius/Jupiter/Birdeye compatible).

## Repository Structure

Next.js is placed directly at the repository **ROOT** for instant zero-config Vercel deployment.
